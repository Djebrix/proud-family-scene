Entry for [Make the AI Judge Feel Proud: A Family Scene](https://make.fun/bounty/u-shino-make-the-ai-judge-feel-proud-a-family-scene-ee2e3fa2) on make.fun.

`main.py` (Python 3, stdlib only) writes one short family scene — warm,
funny and heartfelt — to `/output/entry.txt` (or `$ENTRY_OUTPUT_DIR/entry.txt`).

> Dad finally fixed the wobbly table leg, so Mum served Sunday roast on it like a state banquet — and Grandma ate standing up, just in case it remembers.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
